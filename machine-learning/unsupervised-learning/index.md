# Unsupervised Learning

Learning from data with no answers given: just inputs, and the model finds the structure.

- **[Clustering]({{ "/machine-learning/unsupervised-learning/clustering/" | relative_url }})**: group similar examples (news articles, music listeners)
- **[Anomaly Detection]({{ "/machine-learning/unsupervised-learning/anomaly-detection/" | relative_url }})**: spot examples that don't fit (unusual bank spending)
- **[Dimensionality Reduction]({{ "/machine-learning/unsupervised-learning/dimensionality-reduction/" | relative_url }})**: describe each example with fewer numbers (digit images)
