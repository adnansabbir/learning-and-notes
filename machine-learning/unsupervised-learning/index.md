- **[2.2 Anomaly Detection]({{ "/machine-learning/unsupervised-learning/anomaly-detection/" | relative_url }})**: spot examples that don't fit (unusual bank spending)
- **[2.3 Dimensionality Reduction]({{ "/machine-learning/unsupervised-learning/dimensionality-reduction/" | relative_url }})**: describe each example with fewer numbers (digit images)
